# CineJoy Web

Projeto web do CineJoy em React e Next.js.

## Organizacao

- `frontend`: telas do site.
- `docs`: documentos de organizacao do projeto.

## Como rodar

Abra o PowerShell na pasta do projeto e execute:

```powershell
cd frontend
npm install
npm run dev
```

Depois acesse:

```text
http://localhost:3000
```

Se preferir usar pnpm:

```powershell
cd frontend
pnpm install
pnpm run dev
```

## Observacao

Nesta etapa, as telas usam dados locais para simular o funcionamento.
A API e o banco de dados entram em outra etapa do projeto.
